# PTA 图片日报视觉规范

## 封面

- 以封面新闻专属写实图片为主体，使用“左侧标题、右侧主体场景、底部数据”构图。
- 背景保持接近原始亮度和色彩；不得用重绿色或蓝色蒙版覆盖整张图片。
- 只在左侧标题区和底部数据区使用局部渐变，右上及中心的设备、建筑或自然场景尽量无遮挡。
- 标题使用白色粗体和轻微阴影，重点数字使用黄绿色。
- 标出 `Weekend Roundup / 周末绿色技术汇总`，同时保留 PTA 品牌、日期、重点和四组关键数据。

## 新闻内页

- 每条新闻使用不同且与内容匹配的背景图。
- 文本卡使用半透明深色面板，不使用全屏不透明色罩。
- AI 背景不得包含文字、数字、Logo、水印、图表或虚构铭牌；所有文字由渲染器叠加。

## 背景提示词构图

使用竖版 4:5 写实编辑摄影。让主要设备或场景位于中右侧，左侧留出低细节标题空间；使用自然光和真实材料，禁止文字、Logo、水印和边框。

## 校验

- 输出尺寸为 1080×1350。
- 全部背景哈希不得重复。
- 检查文字溢出和裁切。
- 无视觉模型时仅报告程序校验，不声称完成审美检查。
